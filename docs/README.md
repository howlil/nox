## Writing rules

One audience and one outcome per document. Tutorials produce a repeatable outcome, guides solve a task, references specify observable facts, and explanations justify tradeoffs. State prerequisites, actions, expected results, and known limits. Do not imply that passing mocked CI means real Obsidian/provider acceptance has passed. The code and [AGENTS.md](../AGENTS.md) remain the engineering authority.
